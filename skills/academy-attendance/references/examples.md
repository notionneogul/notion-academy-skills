# 발화 예시

아래 날짜는 전부 2026년 8월 기준이며, **2026-08-21은 금요일, 2026-08-22(오늘)는 토요일**이다. 클래스의 `참여 요일`과 실측 재원 명단은 다음과 같다.

| 클래스 | 참여 요일 | 재원 명단 |
|---|---|---|
| 중3 수학 정규 | 월·수 | 서다현, 윤재우, 임채원, 한소율 |
| 중3 영어 내신반 | 화·목 | 배건우, 임채원, 한소율 |
| 고2 물리 기초 | 토 | 김서준, 오지호 |
| 고2 수학 심화 A | 월·수·금 | 김서준, 박시우, 이하윤, 조민준 |
| 고2 영어 내신반 | 화·목 | 김서준, 박시우, 이하윤 |

**퇴원생**: 정예린(2026-08-08 퇴원, 원래 고2 물리 기초 소속), 조민혁(2026-02-26 퇴원). 둘 다 아래 어떤 신규 출결 예시에도 재원생으로 넣지 않는다.

## 1. 한 명만 — "김서준 오늘 지각"

**발화**: "김서준 오늘 지각"

**클로드가 하는 일**: `name-resolution.md` 「학생 이름으로 지정」으로 김서준을 조회한다. 김서준은 물리·수학·영어 세 과목 페이지를 가지고 있지만, 8월 22일은 **토요일**이라 그날 수업이 있는 클래스는 「고2 물리 기초」(토) 하나뿐이다. 날짜 기반 예외(`name-resolution.md` 4단계)로 그 과목 페이지로 좁히고 되묻지 않는다. (가) 수업일 대조도 토요일=수업일이라 통과다. (나) 중복 조회 — 오늘 김서준의 물리 출석부 행이 없으면 새로 만든다.

**미리보기**:
```
출석부에 1행을 만듭니다.

| 학생 | 날짜 | 출결 | 클래스 |
|---|---|---|---|
| 김서준 | 8/22 | 지각 | 고2 물리 기초 |

이대로 만들까요?
```

**결과**: "출석부에 1행을 만들었습니다. 잘못됐으면 \"방금 거 취소해줘\" 라고 말씀하세요." 지각인데 `보강 날짜`가 없으므로, 쓰기 직전 되물음에서 "보강 날짜를 지금 잡을까요, 나중에 잡을까요?"를 함께 물었고 원장이 "나중에"라고 답해 비워 둔 채 진행했다고 가정한다.

**참고**: 만약 이 발화가 "고2 물리 기초 전체 출석"이었다면, 원래 이 클래스였던 정예린은 명단에 넣지 않는다 — 2026-08-08 퇴원생이라 `name-resolution.md` 「클래스 전체 지정」 3단계의 퇴원생 제외 조회에 걸린다. 오늘 물리 재원 명단은 김서준·오지호 둘뿐이다.

## 2. 반 전체 — "고2 수학 전체 출석"

**발화**: "고2 수학 전체 출석"

**클로드가 하는 일**: 날짜가 없다. 되물음 — "어느 날짜인가요?" 원장이 "8월 24일"이라고 답한다(2026-08-24는 월요일). `name-resolution.md` 「클래스 전체 지정」으로 「고2 수학 심화 A」 재원생 명단을 얻는다(퇴원생 제외) — 김서준, 박시우, 이하윤, 조민준 4명이다. 월요일은 이 클래스의 수업일(월·수·금)이라 (가) 통과. (나) 8/24 행이 아직 없어 전원 신규 생성이다.

**미리보기**:
```
출석부에 4행을 만듭니다.

| 학생 | 날짜 | 출결 | 클래스 |
|---|---|---|---|
| 김서준 | 8/24 | 출석 | 고2 수학 심화 A |
| 박시우 | 8/24 | 출석 | 고2 수학 심화 A |
| 이하윤 | 8/24 | 출석 | 고2 수학 심화 A |
| 조민준 | 8/24 | 출석 | 고2 수학 심화 A |

이대로 만들까요?
```

**결과**: "출석부에 4행을 만들었습니다."

## 3. 전체 + 예외 — "8월 26일 고2 수학 전체 출석, 김서준만 지각, 이하윤 결석"

**발화**: "8월 26일 고2 수학 전체 출석, 김서준만 지각, 이하윤 결석"

(날짜를 예시 2와 다른 8/26로 둔다 — 같은 8/24를 또 쓰면 (나) 중복 검증에 걸려 이 발화 자체가 「수정」 경로로 전환되어 "전체 신규 생성" 예시가 되지 않는다.)

**클로드가 하는 일**: 발화에 클래스가 있으므로 김서준이 여러 과목 페이지를 가지고 있어도(물리·수학·영어) 되묻지 않고 「고2 수학 심화 A」 쪽으로 좁힌다(`name-resolution.md` 4단계, 클래스가 발화에 있으므로 날짜 기반 예외까지 갈 필요도 없다). 8월 26일은 수요일이라 (가) 통과. "결석"은 select 옵션에 없으므로 `미출석`으로 바꿔 쓴다. 예외 두 명(김서준, 이하윤)을 뺀 나머지(박시우, 조민준)는 전원 출석으로 채운다.

**미리보기**:
```
출석부에 4행을 만듭니다.

| 학생 | 날짜 | 출결 | 클래스 |
|---|---|---|---|
| 김서준 | 8/26 | 지각 | 고2 수학 심화 A |
| 이하윤 | 8/26 | 미출석 | 고2 수학 심화 A |
| 박시우 | 8/26 | 출석 | 고2 수학 심화 A |
| 조민준 | 8/26 | 출석 | 고2 수학 심화 A |

이대로 만들까요?
```

**결과**: "출석부에 4행을 만들었습니다." 김서준·이하윤은 지각·미출석인데 `보강 날짜`가 없으므로 되물음 단계에서 함께 확인한다.

## 4. 수정 — "어제 이하윤 결석 아니라 지각이었어"

**발화**: "어제 이하윤 결석 아니라 지각이었어"

**클로드가 하는 일**: "어제" = 2026-08-21(금). 이하윤은 수학·영어 두 과목 페이지를 가지고 있지만, 금요일은 「고2 수학 심화 A」(월·수·금)만 수업일이고 「고2 영어 내신반」(화·목)은 아니다. 날짜 기반 예외로 수학 과목 페이지 하나로 좁혀지므로 되묻지 않는다. 그 과목 페이지로 8/21 출석부 행을 조회한다(사전 검증 (나) 조회 재사용). `출결상태 = 미출석` 인 기존 행이 나온다 — 새로 만들지 않고 수정 경로로 전환한다.

**미리보기**:
```
이하윤의 8/21 출결이 이미 있습니다 (미출석).

| 학생 | 날짜 | 출결(기존 → 변경) | 클래스 |
|---|---|---|---|
| 이하윤 | 8/21 | 미출석 → 지각 | 고2 수학 심화 A |

이대로 고칠까요?
```

**결과**: "이하윤의 8/21 출결을 지각으로 고쳤습니다." 이 행은 이번 실행에서 새로 만든 행이 아니므로, `write-gate.md` 6단계의 자동 되돌리기 대상이 아니다 — 잘못 고쳤으면 다시 미출석으로 고쳐야 한다.

## 5. 과거 날짜 — "지난주 수요일 고2 수학 출결 안 넣었어"

**발화**: "지난주 수요일 고2 수학 출결 안 넣었어"

**클로드가 하는 일**: 오늘(2026-08-22, 토) 기준 지난주 수요일은 2026-08-12다. 「고2 수학 심화 A」는 월·수·금 반이라 수요일은 정상 수업일이다(가). 재원 명단(김서준, 박시우, 이하윤, 조민준)을 얻어 각 학생의 8/12 행을 조회한다(나) — "안 넣었어"라는 말대로 전원 없으면 전원 신규 생성으로 처리한다. 출결상태는 되물어 확인한다("전원 출석으로 넣을까요, 예외가 있나요?").

**미리보기**:
```
출석부에 4행을 만듭니다. (지난주 수요일 8/12, 「고2 수학 심화 A」)

| 학생 | 날짜 | 출결 | 클래스 |
|---|---|---|---|
| 김서준 | 8/12 | 출석 | 고2 수학 심화 A |
| 박시우 | 8/12 | 출석 | 고2 수학 심화 A |
| 이하윤 | 8/12 | 출석 | 고2 수학 심화 A |
| 조민준 | 8/12 | 출석 | 고2 수학 심화 A |

이대로 만들까요?
```

**결과**: "출석부에 4행을 만들었습니다." 과거 날짜라고 절차가 달라지지 않는다 — 되물음·사전 검증·미리보기·승인을 그대로 거친다.

## 6. 수업일 아님 경고 — "8월 22일 중3 수학 출석"

**발화**: "8월 22일 중3 수학 출석"

**클로드가 하는 일**: 「중3 수학 정규」는 월·수 반인데 2026-08-22는 **토요일**이다(가) 위반. 자동으로 멈추지 않고 경고를 미리보기와 함께 보여준다. 원장이 "네, 특강이었어요"라고 답하면 그대로 진행한다.

**미리보기**:
```
⚠️ 8월 22일은 토요일인데 「중3 수학 정규」는 월·수 수업입니다. 보강(특강)인가요?

출석부에 4행을 만듭니다.

| 학생 | 날짜 | 출결 | 클래스 |
|---|---|---|---|
| 서다현 | 8/22 | 출석 | 중3 수학 정규 |
| 윤재우 | 8/22 | 출석 | 중3 수학 정규 |
| 임채원 | 8/22 | 출석 | 중3 수학 정규 |
| 한소율 | 8/22 | 출석 | 중3 수학 정규 |

이대로 만들까요?
```

**결과**: 원장이 승인하면 그대로 만든다. "아니요, 날짜를 잘못 말했어요"라고 답하면 올바른 날짜를 다시 받아 처음부터 진행한다.

## 7. 보강 — "8월 20일 결석한 애들 8월 27일에 보강"

**발화**: "8월 20일 결석한 애들 8월 27일에 보강"

**클로드가 하는 일**: 발화에 클래스가 없다. 되물음 — "어느 클래스의 8월 20일 결석자인가요?" 원장이 "중3 영어요"라고 답한다. 2026-08-20(목)은 「중3 영어 내신반」(화·목, 재원생 배건우·임채원·한소율)의 수업일이다. 그 클래스·그 날짜의 `출결상태 = 미출석` 행을 조회해 배건우·한소율 두 명이 나왔다고 하자. 이 행들은 새로 만드는 게 아니라 **`보강 날짜`만 채우는 수정**이다 — `보강 날짜`를 채웠을 때 `출결상태`가 어떻게 되는지는 `../../academy-core/references/domain-rules.md` 「보강 자동화」가 정한다. 그 규칙대로라 `출결상태`를 따로 지정하지 않는다. `보강 날짜`는 (가) 수업일 대조 대상이 아니다 — 수업일이든 아니든 판정하지 않는다(2026-08-27도 마침 같은 반의 수업일인 목요일이지만, 이는 우연일 뿐 조건은 아니다). `보강완료`는 아직 체크하지 않는다 — 보강 수업을 실제로 마치기 전이라 체크하면 `보강완료`만 있고 실제로는 하지 않은 상태가 된다.

**미리보기**:
```
8월 20일 「중3 영어 내신반」 미출석 2명의 보강을 8월 27일로 잡습니다.

| 학생 | 날짜(미출석) | 보강 날짜 | 클래스 |
|---|---|---|---|
| 배건우 | 8/20 | 8/27 | 중3 영어 내신반 |
| 한소율 | 8/20 | 8/27 | 중3 영어 내신반 |

이대로 고칠까요?
```

**결과**: "2명의 보강 날짜를 8월 27일로 잡았습니다. 보강 수업을 마친 뒤에 \"보강 끝났어\"라고 말씀하시면 보강완료를 체크하겠습니다." 이 두 행도 기존 행 수정이므로 자동 되돌리기 대상이 아니다.
