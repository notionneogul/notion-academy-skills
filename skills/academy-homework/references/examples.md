# academy-homework 예시

학생 이름·클래스는 템플릿 샘플 데이터를 따르고, 날짜·과제 내용은 예시를 위해 세운 값이다. 실제 실행에서는 조회한 값만 쓴다.

과제 DB 는 **행마다 학생 1명**이다(`db-map.md`). 반 전체 과제는 학생 수만큼 행이 생기고, 각 행의 제목과 `과제 안내` 에 같은 과제 이름이 들어간다.

## 1. 반 전체 과제

**발화**: "9월 3일 고2 수학 심화 A 진도 삼각함수 활용, 과제 자이스토리 3단원 15문항"

**클로드가 하는 일**: 2026-09-03 은 수요일, 「고2 수학 심화 A」(월·수·금) 수업일이라 (가) 통과. 재원 명단은 `name-resolution.md` 「클래스 전체 지정」으로 4명. (나) 중복 — 4명 각각 그날·그 과제(`과제 안내` = 「자이스토리 3단원 15문항」) 행이 없다. 평가는 말하지 않았으니 비운다.

```
| 학생 | 날짜 | 과제(제목) | 수업 진도 | 클래스 |
|---|---|---|---|---|
| 김서준 | 9/03 | 자이스토리 3단원 15문항 | 삼각함수 활용 | 고2 수학 심화 A |
| 박시우 | 9/03 | 자이스토리 3단원 15문항 | 삼각함수 활용 | 고2 수학 심화 A |
| 이하윤 | 9/03 | 자이스토리 3단원 15문항 | 삼각함수 활용 | 고2 수학 심화 A |
| 조민준 | 9/03 | 자이스토리 3단원 15문항 | 삼각함수 활용 | 고2 수학 심화 A |

4행을 만듭니다. 평가·피드백은 비워 둡니다. 이대로 만들까요?
```

**결과**: "과제 4건을 만들었습니다."

## 2. 같은 날 과제 둘

**발화**: "9월 3일 고2 수학 과제 두 개야 — 자이스토리 3단원 15문항, 그리고 단어 테스트 준비"

**클로드가 하는 일**: 두 과제를 나눠 받는다. 한 행에 이어 붙이지 않는다 — 평가가 과제마다 따로 붙어야 한다. 예시 1을 이미 넣은 뒤라면 (나) 중복 조회에서 「자이스토리 3단원 15문항」은 4명 모두 걸리고 「단어 테스트 준비」는 걸리지 않는다. 같은 날 다른 과제는 새 행이다.

```
「자이스토리 3단원 15문항」은 4명 모두 이미 있습니다 — 그대로 둡니다.
새로 만들 것:

| 학생 | 날짜 | 과제(제목) | 수업 진도 |
|---|---|---|---|
| 김서준 | 9/03 | 단어 테스트 준비 | 삼각함수 활용 |
| … (4명) | | | |

4행을 만들까요?
```

## 3. 평가 — 그날 과제가 하나

**발화**: "김서준 8월 19일 과제 우수, 피드백은 서술형까지 정확"

**클로드가 하는 일**: (다) 평가 대상 — 김서준·8/19 과제 행이 1개(「유형서 5단원 25문항」)라 그 행이다. 기존 행 수정이다.

```
| 학생 | 날짜 | 과제(제목) | 평가 | 피드백 |
|---|---|---|---|---|
| 김서준 | 8/19 | 유형서 5단원 25문항 | (비어 있음) → 우수 | (비어 있음) → 서술형까지 정확 |

기존 행 1건을 고칩니다. 진행할까요?
```

## 4. 평가 — 그날 과제가 둘이라 어느 과제인지 묻는다

**발화**: "김서준 9월 3일 과제 미흡"

**클로드가 하는 일**: (다) 평가 대상 — 김서준·9/03 과제 행이 2개다(예시 1·2). 원장이 과제 이름을 말하지 않았다. 클로드가 고르지 않고 되묻는다.

```
김서준의 9월 3일 과제가 둘입니다.
  1. 자이스토리 3단원 15문항
  2. 단어 테스트 준비
어느 과제가 미흡인가요? 둘 다라면 "둘 다" 라고 해 주세요.
```

원장이 「1번」이라고 하면 예시 3처럼 그 행 하나만 고친다.

## 5. 같은 과제를 두 번 넣으려 함

**발화**: "9월 3일 김서준 과제 자이스토리 3단원 15문항 우수"

**클로드가 하는 일**: (나) 중복 — 김서준·9/03·「자이스토리 3단원 15문항」 행이 이미 있다. 새로 만들지 않고 기존 행 수정으로 전환한다. 평가만 바꾼다.

```
김서준의 9월 3일 「자이스토리 3단원 15문항」 과제가 이미 있습니다. 새로 만들지 않고 평가만 채웁니다.

| 학생 | 날짜 | 과제(제목) | 평가 |
|---|---|---|---|
| 김서준 | 9/03 | 자이스토리 3단원 15문항 | (비어 있음) → 우수 |
```

## 6. 피드백만 추가

**발화**: "8월 19일 과제에 피드백 달아줘 — 박시우는 최댓값 조건 하나 누락, 이하윤은 오답 원인까지 적어옴"

**클로드가 하는 일**: 두 학생 각각 (다) 평가 대상을 조회한다. 둘 다 8/19 과제가 1개라 바로 정해진다. `피드백` 만 넣고 `평가` 는 넘기지 않는다 — 넘기지 않은 속성은 그대로 유지된다.

## 7. 퇴원생을 이름으로 지목

**발화**: "정예린 오늘 과제 우수"

**클로드가 하는 일**: (라) 퇴원 — 정예린의 `퇴원 날짜` 가 2026-08-08 이다. 오늘 날짜가 그 이후라 쓰기 전에 알린다.

```
⚠️ 정예린은 2026-08-08 퇴원했습니다. 그 이후 날짜의 과제 평가를 쓰려고 합니다. 계속할까요?
```
