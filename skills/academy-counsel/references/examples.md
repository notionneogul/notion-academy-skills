# 발화 예시

아래 날짜는 전부 2026년 8월 기준이며, **2026-08-22(오늘)는 토요일**이다. 실측 재원 명단은 다음과 같다.

| 클래스 | 참여 요일 | 재원 명단 |
|---|---|---|
| 중3 수학 정규 | 월·수 | 서다현, 윤재우, 임채원, 한소율 |
| 중3 영어 내신반 | 화·목 | 배건우, 임채원, 한소율 |
| 고2 물리 기초 | 토 | 김서준, 오지호 |
| 고2 수학 심화 A | 월·수·금 | 김서준, 박시우, 이하윤, 조민준 |
| 고2 영어 내신반 | 화·목 | 김서준, 박시우, 이하윤 |

서다현·윤재우·배건우·오지호·조민준은 과목 페이지가 하나뿐이다. 김서준은 셋(물리·수학·영어), 박시우·이하윤·임채원·한소율은 둘(수학·영어)이다.

**퇴원생**: 정예린(2026-08-08 퇴원), 조민혁(2026-02-26 퇴원). 상담은 요일 제약도, 퇴원 정합 규칙도 적용되지 않는다(「사전 검증」참고) — 퇴원 날짜 이후 시점이어도 상담 자체를 막지 않고 미리보기에 한 줄만 알린다. 예시 1~5는 이 규칙과 무관하게 재원 중인 학생만 다루고, 예시 6이 퇴원 이후 상담(정예린)을 별도로 시연한다.

**실측 상담 기록(라이브 조회로 확인한 실제 문장, 최근순 10건)** — 학생별 연결은 조회 범위 밖이라 이 표만으로는 알 수 없다. 아래 예시에서 이 문장을 인용할 때는 그때마다 "학생 연결은 예시를 위한 가정"이라고 명시한다.

| 날짜 | 상담 기록 |
|---|---|
| 8/12 | 고2 수학 심화반 편입 후 적응 상황 점검. 진도 속도는 따라오는 중 |
| 8/06 | 수학 시간대 변경 요청, 수요일 6시로 조율 |
| 8/03 | 학부모님 통화 - 8월 중 이사로 퇴원 예정 안내받음. 8/8까지 수강 |
| 7/22 | 이전 학원 진도 격차 확인. 단어 범위를 별도로 조정하기로 함 |
| 7/08 | 학교 밴드부 공연 준비로 8월 초 결석 예정이라고 미리 안내받음 |
| 6/27 | 학부모님 통화 - 2학기 중간고사 목표 조정. 수학 3등급에서 2등급으로 목표 합의 |
| 6/24 | 천식으로 여름철 컨디션 관리 요청. 무리한 보강은 자제해 달라고 하심 |
| 6/23 | 영어 앞부분 결손 안내. 화요일 야자 이후 등원이라 보충이 필요하다고 설명드림 |
| 6/07 | 영어 클래스 레벨 상향 논의. 9월부터 심화반 이동 제안드림 |
| 5/23 | 학부모님 방문 상담 - 여름 특강 수강 여부 논의. 수학만 신청하기로 함 |

8/03 행은 "8월 중 이사로 퇴원 예정... 8/8까지 수강"이라는 내용이 정예린의 실제 퇴원일(2026-08-08)과 일치한다 — 이 학생과의 연결이 사실일 가능성이 높지만, 이 사실을 단정해 새 예시를 만들지는 않는다(이미 지난 일이고, 정예린은 퇴원생이라 신규 상담 대상이 아니다).

**템플릿 안내문 예시(제작자 템플릿 원본, 실제 기록이 아니다)**: `상담 내용 입력`, `상담 내용을 편하게 쭉 작성하기`, `상담 내용 작성하기`. 구매자가 템플릿을 막 복제한 직후에는 이런 값이 남아 있을 수 있다.

아래 신규 상담 예시(1~3, 6)는 모두 「사전 검증 (나)」 조회(같은 날·같은 과목 페이지)에서 0건이 나온 경우 — 그날 그 학생의 첫 상담 — 를 다룬다. 이미 그날 그 학생 상담이 있는 경우의 처리(막지 않고 알리기)는 SKILL.md 「사전 검증」을 본다.

## 1. 기본 — "김서준 어머니 상담했어. 수학 성적 걱정하시고 주 1회 추가 보강 원하심"

이 예시는 새로 시작하는 상황이다 — 앞의 예시와는 무관하다.

**발화**: "김서준 어머니 상담했어. 수학 성적 걱정하시고 주 1회 추가 보강 원하심"

**클로드가 하는 일**: 날짜 언급이 없으므로 오늘(2026-08-22)로 본다. 김서준은 과목 페이지가 셋(물리·수학·영어)이지만 발화에 "수학"이 명시돼 있어 되묻지 않고 「고2 수학 심화 A」 김서준 과목 페이지로 정한다. 원장이 말한 내용만 문장으로 다듬는다 — "성적 걱정"과 "주 1회 추가 보강 희망"만 넣고, "학부모가 불안해하신다" 같은 해석은 덧붙이지 않는다.

**미리보기**:
```
재원생 상담에 1행을 만듭니다.

| 학생 | 날짜 | 상담 기록 |
|---|---|---|
| 김서준(고2 수학 심화 A) | 8/22 | 어머니 상담. 수학 성적을 걱정하시며 주 1회 추가 보강을 원하심 |

이대로 만들까요?
```

**결과**: "재원생 상담에 1행을 만들었습니다. 잘못됐으면 \"방금 거 취소해줘\" 라고 말씀하세요."

## 2. 과목 되물음 — "한소율 학부모님이랑 통화했어. 다음 학기 목표 얘기했고, 3등급에서 2등급으로 올리자고 합의했어"

독립 상황이다.

**발화**: "한소율 학부모님이랑 통화했어. 다음 학기 목표 얘기했고, 3등급에서 2등급으로 올리자고 합의했어"

**클로드가 하는 일**: 한소율은 과목 페이지가 둘(중3 수학 정규·중3 영어 내신반)이고, 발화 어디에도 과목을 특정할 단어가 없다 — 등급 목표는 수학·영어 어느 쪽에도 해당할 수 있다. `name-resolution.md` 「학생 이름으로 지정」 4단계에 따라 되묻는다.

> 수학 상담인가요, 영어 상담인가요?

원장이 "수학"이라고 답한다. 「중3 수학 정규」 한소율 과목 페이지로 정한다.

**미리보기**:
```
재원생 상담에 1행을 만듭니다.

| 학생 | 날짜 | 상담 기록 |
|---|---|---|
| 한소율(중3 수학 정규) | 8/22 | 학부모님 통화. 2학기 목표를 수학 3등급에서 2등급으로 올리는 것으로 합의 |

이대로 만들까요?
```

**결과**: "재원생 상담에 1행을 만들었습니다. 잘못됐으면 \"방금 거 취소해줘\" 라고 말씀하세요."

## 3. 지어내기 거절 — "서다현 아버님이랑 통화했어. 등원 시간을 15분 당겨달라고 하셔서 조율했어"

독립 상황이다.

**발화**: "서다현 아버님이랑 통화했어. 등원 시간을 15분 당겨달라고 하셔서 조율했어"

**클로드가 하는 일**: 서다현은 과목 페이지가 하나(중3 수학 정규)라 되묻지 않는다. 원장이 말한 것은 "등원 시간 15분 조정" 뿐이다. 여기에 "아버님이 만족하셨다", "아이의 학습 부담을 줄이기 위해" 같은 원장이 말하지 않은 이유나 반응을 채우지 않는다 — 말한 것만 문장으로 다듬는다.

**미리보기**:
```
재원생 상담에 1행을 만듭니다.

| 학생 | 날짜 | 상담 기록 |
|---|---|---|
| 서다현(중3 수학 정규) | 8/22 | 아버님 통화. 등원 시간을 15분 앞당기는 것으로 조율 |

이대로 만들까요?
```

**결과**: "재원생 상담에 1행을 만들었습니다. 잘못됐으면 \"방금 거 취소해줘\" 라고 말씀하세요."

## 4. 과거 상담 기록 수정 — "윤재우 저번 상담 기록에 한 줄 추가해줘. 다음 상담은 9월 초에 하기로 했다고"

독립 상황이다.

**발화**: "윤재우 저번 상담 기록에 한 줄 추가해줘. 다음 상담은 9월 초에 하기로 했다고"

**클로드가 하는 일**: 새 행이 아니라 기존 행 수정이다. 윤재우는 과목 페이지가 하나(중3 수학 정규)라 되묻지 않는다. 가장 최근 상담 행을 조회한다.

```sql
SELECT id, url, "date:상담 날짜:start", "상담 기록"
FROM "collection://<재원생 상담>"
WHERE "이름 붙여넣기" LIKE '%<윤재우 중3 수학 과목 페이지 대시 없는 uuid>%'
ORDER BY "date:상담 날짜:start" DESC LIMIT 1
```

결과로 2026-06-24 행, `상담 기록`이 "천식으로 여름철 컨디션 관리 요청. 무리한 보강은 자제해 달라고 하심"이 나왔다고 하자 — **이 문장 자체는 실측 10건 표에서 가져온 실제 기록이고, 윤재우에게 붙인 것은 이 예시를 위한 가정이다.** 템플릿 안내문이 아니라 실제 문장이므로 이어붙인다. `상담 기록`은 부분 추가가 안 되므로 기존 문장 뒤에 새 문장을 이은 전체 텍스트를 만든다.

**미리보기**:
```
윤재우의 6/24 상담 기록에 한 줄을 추가합니다(기존 행 수정).

| 기존 상담 기록 | 추가 후 |
|---|---|
| 천식으로 여름철 컨디션 관리 요청. 무리한 보강은 자제해 달라고 하심 | ... (위와 동일) 다음 상담은 9월 초로 예정 |

이대로 고칠까요?
```

**결과**: "윤재우의 6/24 상담 기록에 한 줄을 추가했습니다." 이전 실행에서 만든 행이라 건별 승인을 받았고, 되돌리기 범위(이번 실행에서 만든 행)에는 들지 않는다.

## 5. 템플릿 안내문 구별 — "이하윤 저번 상담 어땠는지 보고 이어서 한 줄 추가해줘"

독립 상황이다. 이하윤은 과목 페이지가 둘(고2 수학 심화 A·고2 영어 내신반)이라 되묻는다 — "수학인가요, 영어인가요?" 원장이 "영어"라고 답했다고 하자. 가장 최근 상담 행을 조회한다.

```sql
SELECT id, url, "date:상담 날짜:start", "상담 기록"
FROM "collection://<재원생 상담>"
WHERE "이름 붙여넣기" LIKE '%<이하윤 고2 영어 과목 페이지 대시 없는 uuid>%'
ORDER BY "date:상담 날짜:start" DESC LIMIT 1
```

결과가 `상담 내용 입력`이라고 하자 — 「템플릿 안내문 구별」에 해당하는 값이다. 실제 상담 기록으로 읽지 않고, 이어붙일 대상이 없다고 원장에게 알린다.

> 이하윤(영어)의 가장 최근 상담 기록이 `상담 내용 입력`으로 되어 있습니다 — 템플릿 안내문으로 보이고 실제 상담 기록이 아직 없는 것 같습니다. 이어붙이는 대신 새 상담으로 기록할까요?

원장이 "어, 그럼 새로 만들어줘"라고 답하면 예시 1과 같은 절차로 신규 행을 만든다(이 스킬의 「기본」 경로로 이어진다). 이 예시는 여기서 멈춘다.

## 6. 퇴원 이후 상담 — "정예린 어머니랑 퇴원 상담했어. 전학 때문에 그만두게 됐다고 설명 들었어"

독립 상황이다.

**발화**: "정예린 어머니랑 퇴원 상담했어. 전학 때문에 그만두게 됐다고 설명 들었어"

**클로드가 하는 일**: 정예린은 2026-08-08 퇴원생이고, 오늘(8/22)은 그 이후다. 「사전 검증」의 「퇴원 정합」에 따라 이 자체로 막지는 않는다 — 퇴원 사유 상담은 퇴원 이후에도 정당하다. 정예린은 과목 페이지가 하나(고2 물리 기초)뿐이라 되묻지 않는다. 원장이 말한 것은 "전학으로 퇴원"뿐이므로 그대로 다듬는다.

```
재원생 상담에 1행을 만듭니다.

|---|---|---|

이대로 만들까요?
```

**결과**: "재원생 상담에 1행을 만들었습니다. 잘못됐으면 \"방금 거 취소해줘\" 라고 말씀하세요."
