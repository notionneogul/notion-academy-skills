# 발화 예시

| 발화 | 모드 | 처리 |
|---|---|---|
| "오늘 뭐 해야 해?" | 할 일 | 네 항목 전부 |
| "보강 잡아야 할 애들" | 할 일 (부분) | 보강 필요만 |
| "미납 누구야?" | 할 일 (부분) | 미납만, 오래된 순 |
| "위험한 학생 있어?" | 이탈 위험 | 전체 순위 |
| "한소율 요즘 어때?" | 상담 준비 | 그 학생 요약 |
| "내일 김서준 어머니 상담인데" | 상담 준비 | 김서준 요약 + 할 말 |
| "이번 주 정리해줘" | 할 일 | 클로드가 이번 주 시작·끝 날짜를 계산해 리터럴로 넣고 그 범위로 집계 |
| "고2 수학반만 봐줘" | 할 일 (필터) | 클래스명으로 클래스를 찾아 그 클래스 소속 과목 페이지만 본다. `학년` 은 formula 라 조회되지 않으므로 학년으로 거르지 않는다. 클래스명이 애매하면 클래스 목록을 보여 주고 되묻는다 |
