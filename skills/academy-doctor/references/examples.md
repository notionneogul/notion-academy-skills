# 발화 예시

| 발화 | 해석 | 처리 |
|---|---|---|
| "데이터 점검해줘" | 전체 검사 | 다섯 분류 전부, 심각도별로 |
| "이상한 데이터 있어?" | 전체 검사 | 같음 |
| "오류만 보여줘" | 심각도 필터 | 오류 단계만 |
| "샘플 데이터 아직 남았어?" | 플레이스홀더만 | 잔존 문자열 검사만. 여러 검사에 동시에 걸리면 `academy-setup` 의 「샘플 데이터 정리」로 통째로 치우는 길을 안내한다 (`references/checks.md` 「플레이스홀더 잔존」) |
| "출석부만 점검" | DB 필터 | 그 DB 관련 항목만 |
| "고쳐줘" | 수정 요청 | 고칠 수 있는 항목을 나열하고 건별 승인을 받은 뒤 수정한다 |
| "경고만 따로 정리해줘" | 심각도 필터 | 경고 단계만 |
| "중복된 거 있어?" | 분류 필터 | 중복 분류만 |
| "수강료 쪽 이상한 거 없어?" | DB 필터 | 수강료 납부·납부 월 관련 항목만 |
