# 월말 리포트 예시

아래 예시는 전부 **오늘이 2026-08-25(화)** 인 상황이다. 쓰는 반은 하나다 — 「고2 수학 심화 A」(참여 요일 월·수·금, 재원 4명: 김서준·박시우·이하윤·조민준). **8월 1일부터 25일까지의 월·수·금 수업일은 8/03·8/05·8/07·8/10·8/12·8/14·8/17·8/19·8/21·8/24 열 번이다** — 요일은 `python3` 로 검산했다.

**퇴원생**: 정예린(2026-08-08 퇴원), 조민혁(2026-02-26 퇴원). 아래 어떤 예시에도 대상으로 넣지 않는다.

**8월은 아직 끝나지 않았다.** 원장이 「8월」을 지목했으므로 그대로 만들되, 담은 범위가 8/01~8/25 라는 것을 미리보기에 밝힌다(「절차」 1단계). 발화가 달을 말하지 않았을 때의 기본값인 「지난달」은 아래 예시에 나오지 않는다 — 네 예시 모두 원장이 달을 지목했거나 「이번 달」이라고 말한 경우다.

## 이 예시들이 실측인지 가정인지

다른 스킬의 예시와 같은 원칙이다. 붙인 파일은 **학부모가 우피로 보는 자리**에 남으므로, 무엇이 실제 조회 결과이고 무엇이 예시를 위해 세운 가정인지 여기서 먼저 갈라 둔다.

## 1. 반 전체 — "고2 수학 심화 A 8월 월말 리포트 만들어줘"

독립 상황이다. `~/.academy/report-form.html` 이 있고 학원 이름이 「한빛수학학원」으로 고쳐져 있다.

**발화**: "고2 수학 심화 A 8월 월말 리포트 만들어줘"

**클로드가 하는 일**: 1단계 — `../../academy-core/references/name-resolution.md` 「클래스 전체 지정」으로 재원 4명을 얻는다(정예린·조민혁은 그 절차가 이미 뺀다). 기간은 원장이 지목한 8월이고, 오늘이 8/25 라 8/01~8/25 까지만 담긴다. **이어서 4명의 과목 페이지 본문을 읽어 붙일 자리를 확인한다** — 「월말 리포트」 콜아웃은 넷 다 있고 8월 파일은 아무에게도 없다(반대 경우가 예시 3 이다). 2단계 — 원장 양식이 있으므로 그것을 읽는다. 3단계 — `../../academy-message/SKILL.md` 「3. 근거 수집」 그대로 출결·시험·과제·상담을 읽는다. **시험 두 회차의 총점이 50 과 40 으로 달라 원점수를 그대로 견주지 않고 득점률로 환산한다.** 8/12 과제 행의 「보통」은 그 행 과제(자이스토리 수학I 2단원 20문항)의 평가다(`../../academy-core/references/domain-rules.md` 「과제 평가 대상」). 4단계 — 학생마다 양식을 복사해 채우고 크롬으로 PDF 로 만든다.

## 2. 원장 양식이 없다 — 기본 양식을 쓰고 있다고 밝힌다

## 3. 같은 달이 이미 붙어 있다 — "고2 수학 심화 A 8월 월말 리포트 다시 만들어줘"

독립 상황이다. **이하윤의 과목 페이지 「월말 리포트」 콜아웃에 8월 파일이 이미 한 줄 붙어 있다고 본다** — 이 전제는 예시를 위한 가정이다. 나머지 셋에는 없다.

**발화**: "고2 수학 심화 A 8월 월말 리포트 다시 만들어줘"

**클로드가 하는 일**: **1단계에서 대상을 정한 뒤 학생마다 과목 페이지 본문을 읽는데**, 이하윤의 콜아웃에 「2026년 8월 월말 리포트」 줄이 이미 있다. **그 줄을 덮어쓰지도 지우지도 않는다** — 이하윤을 빼 두고, 승인을 받기 전인 5단계 미리보기에 누구를 왜 빼는지 담는다. 나머지 단계는 예시 1 과 같다.

**미리보기 꼬리**:

```
이하윤은 8월 리포트가 이미 붙어 있어 이번에는 빼 두었습니다.
나머지 3명(김서준·박시우·조민준)에게만 붙일까요?

이하윤도 다시 만들기를 원하시면 그렇게 말씀해 주십시오. 다만 이미 붙어 있는 줄을
지우지 않으므로 그 콜아웃에 8월 줄이 두 개가 됩니다 — 필요 없는 쪽은 노션에서
직접 지우셔야 합니다. 클로드는 붙인 파일 줄을 지우지 않습니다.
```

원장이 "3명만 해줘" 라고 한다.

**붙인 뒤 보고**:

```
3명의 과목 페이지에 붙였습니다 — 김서준 · 박시우 · 조민준.
이하윤은 8월 리포트가 이미 있어 건너뛰었습니다. 그 페이지는 그대로 두었습니다.
이하윤 PDF 는 `~/.academy/reports/2026-08/2026-08_이하윤_수학_월말리포트.pdf` 에 만들어 두었으니, 다시 붙이기를 원하시면 말씀해 주십시오.
```

## 4. 본문이 비어 있다 — 붙이지 않고 알린다

독립 상황이다. 나머지 조건은 예시 1 과 같은데, **박시우의 과목 페이지 본문이 통째로 비어 있다.**

**클로드가 하는 일**: 1단계에서 본문을 읽었더니 `notion-fetch` 가 「이 페이지는 비어 있습니다」로 답한다. 과목 페이지는 DB 기본 템플릿에서 만들어지므로 콜아웃 넷과 리포트를 담을 콜아웃 하나가 있는 것이 정상이다 — **비어 있다는 것은 그 페이지에 템플릿이 적용되지 않았다는 뜻이다.** 박시우를 빼고, 승인을 받기 전인 5단계 미리보기에 그 사실을 담는다. **템플릿을 대신 적용하지 않는다.**

```
박시우 학생은 이번에 빼 두었습니다.

과목 페이지 본문이 비어 있습니다. 다른 학생 페이지에는 출결 현황 🎒 · 시험 결과 📝 ·
시험 차트 📊 · 과제 현황 🏃‍♂️ 콜아웃이 있는데 이 페이지에는 하나도 없습니다.
여기에 리포트만 붙이면 대시보드 없이 PDF 한 줄만 있는 페이지가 되고,
그 페이지는 학부모가 우피로 보시는 자리입니다.

노션에서 박시우 수학 페이지를 열고 템플릿을 적용하신 뒤 다시 불러 주십시오.
제가 대신 적용하지는 않겠습니다 — 인라인 데이터베이스가 딸린 구조라
잘못 만들면 되돌리기가 어렵습니다.

나머지 3명(김서준 · 이하윤 · 조민준)은 그대로 붙일까요?
```

원장이 "응" 하면 셋만 붙이고, 결과 보고에 박시우를 왜 뺐는지 다시 적는다.

## 5. 상담 기록이 없다 — 빈 칸으로 두지 않는다

독립 상황이다. 상담 관련 사실은 **전부 실측**이다 — 박시우(2026-05-23)·조민준(2026-08-12)에게는 기록이 있고, **김서준 수학·이하윤 수학에는 없다.**

**발화**: "이번 달 리포트 뽑아줘"

**되물음**: 어느 반인지 말하지 않았다. `../../academy-core/references/write-gate.md` 1단계대로 되묻는다.

```
어느 반의 월말 리포트를 만들까요? 기간은 이번 달(2026년 8월)로 보겠습니다.
```

원장이 "고2 수학 심화 A" 라고 답한다.

**클로드가 하는 일**: 3단계에서 `재원생 상담` 을 8/01~8/25 로 좁혀 읽으면 조민준 1건만 나오고 나머지 셋은 0행이다. **0행이 진짜 없는 것인지 범위 밖으로 밀려난 것인지 가르는 절차는 `../../academy-message/SKILL.md` 「3. 근거 수집」에 있다** — 그대로 따른 결과가 아래 표다.

| 학생 | 8월 조회 | 날짜 조건 없이 최근 1건 | 리포트 상담 항목에 들어가는 것 |
|---|---|---|---|
| 김서준 | 0행 | 없음 | 0회 · 이번 달 기록 없음 |
| 박시우 | 0행 | 2026-05-23 | 0회 · 이번 달 기록 없음 |
| 이하윤 | 0행 | 없음 | 0회 · 이번 달 기록 없음 |
| 조민준 | 1행 (8/12) | 2026-08-12 | 1회 (8/12) · 상담 내용 요약 |

**빈 칸으로 두지 않는다.** 상담 항목 자체를 빼지도 않는다 — 항목이 사라지면 학부모는 무엇이 빠졌는지 알 수 없고, 빈 칸으로 두면 누락으로 읽는다. 김서준의 리포트에는 이렇게 들어간다.

```
[상담]
이번 달에는 상담 기록이 없습니다.
```

**박시우의 5/23 기록을 8월 리포트에 끌어오지 않는다.** 그 자리는 그 달을 담는 칸이다. 다만 원장이 판단할 근거가 되므로 미리보기에 한 줄로 알린다.

**미리보기 꼬리**:

```
상담 항목은 이렇게 나갑니다.

| 학생 | 상담 |
|---|---|
| 김서준 | 0회 · 이번 달 기록 없음 |
| 박시우 | 0회 · 이번 달 기록 없음 (마지막 기록은 2026-05-23 입니다) |
| 이하윤 | 0회 · 이번 달 기록 없음 |
| 조민준 | 1회 · 8/12 |

박시우는 마지막 상담이 석 달 전입니다. 이대로 내보내도 될지, 상담을 먼저 잡으실지
확인해 주십시오. 상담 내용을 지어내 채우지는 않습니다.
```
