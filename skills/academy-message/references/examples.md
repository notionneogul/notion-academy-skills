# academy-message 예시

아래 학생·점수·날짜는 **예시를 위해 세운 값**이다. 실제 실행에서는 3단계에서 조회한 값만 쓴다.

## 예시 1 — 반 전체 총평, 양식에 자리가 있음

**발화:** "고2 수학 심화 A 총평 써줘"

**클로드가 하는 일:**

1. `name-resolution.md` 「클래스 전체 지정」으로 재원생 과목 페이지 4개를 찾는다(퇴원생 제외)
2. `문자 양식` 에서 `사용` 이 켜진 행을 읽는다. 「위클리리포트」 양식 본문에 `#{클로드총평}` 이 있다
3. 학생마다 최근 한 달 출석부·시험·과제를 읽는다. 시험은 카테고리 `총점` 을 따로 읽어 백분율로 환산한다
4. 총평 초안을 쓴다

**미리보기:**

```
읽은 기간: 2026-08-12 ~ 2026-09-12 (한 달)
실리는 양식: 위클리리포트 — Make 가 보내는 시각 전에 써야 이번 회차에 실립니다.

| 학생 | 기존 총평 | 새 총평 |
|---|---|---|
| 김서준 수학 | (비어 있음) | 최근 세 번의 데일리테스트가 70% → 78% → 88% 로 오르고 있습니다. 과제 평가도 보통에서 우수로 올라섰습니다. |
| 박시우 수학 | (비어 있음) | 8월 들어 결석이 두 번 있었지만 모두 보강으로 채웠습니다. 시험은 80% 안팎에서 안정적입니다. |
| … | | |

4명의 `클로드총평` 을 채울까요?
```

**승인 후:** 4행의 `클로드총평` 만 쓴다. 「발송은 Make 가 합니다」로 보고를 맺는다.

## 예시 2 — 양식에 `#{클로드총평}` 이 없음

**발화:** "김서준 총평 써줘"

**클로드가 하는 일:** `사용` 이 켜진 양식을 읽었는데 어느 본문에도 `#{클로드총평}` 이 없다. 쓰기 전에 멈추고 묻는다.

```
지금 켜진 문자 양식(데일리리포트·출석알림)에는 #{클로드총평} 자리가 없습니다.
총평을 써 두어도 알림톡에는 실리지 않습니다. 그래도 써 둘까요?
양식에 총평 자리를 넣으시려면 "위클리 리포트 양식에 총평 넣어줘" 라고 해 주세요(academy-template).
```

원장이 「그래도 써 둬」라고 하면 예시 1과 같은 흐름으로 간다.

## 예시 3 — 근거가 오래됨

**발화:** "오지호 물리 총평 써줘"

**클로드가 하는 일:** 한 달 범위에서 시험이 0행이다. 날짜 조건 없이 가장 최근 시험 행을 보니 3개월 전이다. `completeness-checks.md` 「총평」대로 되묻는다.

```
오지호 물리의 마지막 시험 기록이 6월 13일(3개월 전)입니다.
출결·과제만으로 총평을 쓸까요, 아니면 시험 기록을 먼저 넣으실까요?
```

「출결·과제만으로」라고 하면 시험 이야기는 빼고 쓴다. 없는 시험 결과를 지어내지 않는다.

## 예시 4 — 「보내줘」까지 말함

**발화:** "고2 영어 총평 쓰고 보내줘"

**클로드가 하는 일:** 총평은 예시 1처럼 쓴다. 보내지는 않는다 — `domain-rules.md` 「발송」대로 이렇게 알린다.

```
총평 3건을 채웠습니다. 발송은 이 스킬이 하지 않습니다.
위클리리포트 알림톡은 Make 가 정해진 시간에 보내고, 그때 채운 총평이 실립니다.
```
