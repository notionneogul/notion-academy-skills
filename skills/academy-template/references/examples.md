# academy-template 예시

양식 이름과 본문은 예시를 위해 세운 값이다. 변수 대조 결과는 2026-09-12 실측한 `학생 과목별 페이지` 속성 이름을 따른다.

## 예시 1 — 새 출결 알림 문구

**발화:** "출결 알림 문구 새로 만들어줘. 「#{이름} 학생 오늘 출결 알려드립니다. #{출석문자} 자세한 건 여기서 보세요 #{개별페이지링크}」"

**클로드가 하는 일:**

1. `선택` 은 「출석알림」이다. `문자 양식` 에 「출석알림」이면서 `사용` 이 켜진 행이 이미 하나 있다 — 그걸 끄고 새 행을 켤지, 새 행은 꺼 둘지 묻는다
2. 변수 대조 — `#{이름}`(속성 `이름`) · `#{출석문자}`(속성 `출석문자`) · `#{개별페이지링크}`(속성 `개별 페이지 링크`, 띄어쓰기 뺌) 전부 있다
3. 미리보기

```
| 이름 | 선택 | 사용 | 본문 |
|---|---|---|---|
| 출결 알림 - 짧은 버전 | 출석알림 | 꺼 둠 | #{이름} 학생 오늘 출결 알려드립니다.
#{출석문자}
자세한 건 여기서 보세요 #{개별페이지링크} |

이 행을 만들까요? 기존 「출석알림」 양식은 그대로 켜 둡니다.
```

**승인 후:** `notion-create-pages` 로 한 행을 만든다. 「발송은 Make 가 합니다 — 출결 알림은 출석부에 기록되는 순간 나갑니다. 실제로 무엇이 채워지는지는 학생 한 명의 `양식(출결알림)` 칸에서 확인해 주세요」로 맺는다.

## 예시 2 — 없는 변수가 든 문구

**발화:** "이 문구로 출결 알림 만들어줘. 「#{이름} 학생 #{출결문자}」"

**클로드가 하는 일:** 변수 대조에서 `#{출결문자}` 가 걸린다. 띄어쓰기를 뺀 속성 이름 목록에 `출결문자` 가 없다. **쓰기 전에 멈춘다.**

```
#{출결문자} 에 해당하는 속성이 없습니다. #{출석문자} 를 뜻하셨나요?
템플릿의 「나만의 양식 만들기」 설명에 #{출결문자} 라고 적혀 있는데, 그 설명이 오타입니다.
이대로 쓰면 학부모에게 "#{출결문자}" 가 글자 그대로 나갑니다.
```

원장이 「출석문자로 바꿔」라고 하면 다시 대조하고 예시 1처럼 진행한다. 「그대로 써」라고 해도 쓰지 않는다.

## 예시 3 — 기존 양식에 총평 넣기

**발화:** "위클리 리포트 양식에 총평 넣어줘"

**클로드가 하는 일:**

1. `선택` 이 「위클리리포트」이고 `사용` 이 켜진 행을 찾는다. 지금 본문을 보인다
2. 맺음말 앞에 `■ 선생님 총평\n#{클로드총평}` 을 넣은 안을 만든다. 변수 대조 — `#{클로드총평}` 은 속성 `클로드총평` 과 같다
3. 미리보기 — 고치기 전과 후를 나란히

```
| 이름 | 선택 | 고치기 전 | 고친 뒤 |
|---|---|---|---|
| 위클리리포트 | 위클리리포트 | …■ 과제\n#{위클리과제}\n\n문의사항 있으시면… | …■ 과제\n#{위클리과제}\n\n■ 선생님 총평\n#{클로드총평}\n\n문의사항 있으시면… |

이 행의 본문을 고칠까요?
```

**승인 후:** `update_properties` 로 `문자 양식` 만 고친다. 「총평은 `academy-message` 로 채우고, Make 가 위클리 리포트를 보내는 시각 전에 써 두셔야 실립니다」로 맺는다.
