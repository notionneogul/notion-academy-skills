# 데이터베이스 지문과 설정 파일 규격

## 설정 파일 규격

스킬은 사용자의 노션 템플릿과 연결하기 위해 설정 파일을 읽습니다. 경로는 `~/.academy/config.json`입니다.

파일 형식은 다음과 같습니다:

```json
{
  "template_version": "2.0",
  "root_page": "https://www.notion.so/...",
  "connected_at": "2026-08-21",
  "databases": {
    "학생": "collection://...",
    "학생 과목별 페이지": "collection://...",
    "클래스": "collection://...",
    "출석부": "collection://...",
    "과제": "collection://...",
    "시험": "collection://...",
    "시험 카테고리": "collection://...",
    "수강료 납부": "collection://...",
    "납부 월": "collection://...",
    "재원생 상담": "collection://...",
    "신입생": "collection://...",
    "학교": "collection://...",
    "클래스 공지사항": "collection://...",
    "문자 양식": "collection://...",
    "과제 M": "collection://..."
  }
}
```

- `template_version`: 템플릿 버전(문자열)
- `root_page`: 루트 페이지 URL(문자열)
- `connected_at`: 연결 날짜(문자열, `YYYY-MM-DD` 형식)
- `databases`: 한글 데이터베이스명을 `collection://<uuid>` 형식의 문자열에 매핑합니다(15개)

파일이 없거나 `databases` 키에 15개 미만의 데이터베이스가 있으면 연결되지 않은 상태로 보고 `academy-setup` 실행을 안내한 뒤 중단합니다.

## 스키마 지문표

각 데이터베이스는 이름만으로 판별하지 않고 다음 속성 조합으로 확인합니다:

| 데이터베이스 | 지문 (이 속성들이 모두 있어야 한다) |
|---|---|
| 학생 | `이름`(title) · `생년월일`(date) · `성별`(select: 남/여) · `학년 수정`(number, 수식 `학년`의 수동 보정값) · `학교`(relation→학교) · `학부모 전화번호`·`학생 전화번호`(phone_number) · `특이사항`(text) · `퇴원 날짜`(date) · `학생 과목별 페이지`(relation→학생 과목별 페이지) |
| 학생 과목별 페이지 | `이름`(title) · `학생`(relation→학생) · `클래스`(relation→클래스) · `출석부`(relation→출석부) · `과제`(relation→과제) · `시험`(relation→시험) · `재원생 상담`(relation→재원생 상담) · `수강료 납부`(relation→수강료 납부) · `문자 양식`(relation→문자 양식) · `KPI 점수`(formula) · `전송완료`(checkbox) |
| 클래스 | `클래스명`(title) · `참여 요일`(multi_select) · `시작 시간`(text) · `운영시간(분)`(number) · `담당 선생님`(select) |
| 출석부 | `출석 날짜`(date) · `출결상태`(select: 출석/지각/미출석/보강) · `보강 날짜`(date) · `보강완료`(checkbox) · `학생`(relation→**학생 과목별 페이지**) |
| 과제 | `수업 날짜`(date) · `수업 진도`(text) · `과제 안내`(text) · `평가`(select: 우수/보통/미흡) · `피드백`(text) · `이름 붙여넣기`(relation→**학생 과목별 페이지**) · `과제 M`(relation→과제 M) |
| 시험 | `시험 날짜`(date) · `점수`·`재시험 점수`(number) · `평가`(select: 통과/재시험/미응시) · `피드백`(text) · `시험 카테고리`(relation→시험 카테고리) · `이름 붙여넣기`(relation→**학생 과목별 페이지**) |
| 시험 카테고리 | `시험명`(title) · `유형`(select: 단어시험/모의고사/데일리테스트/주간평가/월간평가) · `총점`(number) · `시험`(relation→시험) |
| 수강료 납부 | `수강료`(number, 원) · `상태`(status: 미납/납부 완료) · `납부 날짜`(date) · `납부 월`(relation→납부 월) · `이름 붙여넣기`(relation→**학생 과목별 페이지**) |
| 납부 월 | `납부 년월`(title) — 속성이 이것 하나뿐인 것이 지문이다 |
| 재원생 상담 | `상담 날짜`(date) · `상담 기록`(text) · `이름 붙여넣기`(relation→**학생 과목별 페이지**) |
| 신입생 | `이름`(title) · `상태`(status: 상담 전/상담 중/등록 완료/미등록) · `상담 날짜`(date) · `생년월일`(date) · `성별`(select: 남/여) · `학년 수정`(number) · `학교`(relation→학교) · `학부모 전화번호`·`학생 전화번호`(phone_number) · `특이사항`(text) · `재원생 등록`(button) |
| 학교 | `학교명`(title) · `선택`(select: 초등학교/중학교/고등학교) · `인원 수`(rollup) |
| 클래스 공지사항 | `이름`(title) · `클래스`(relation→클래스) · `공유 링크`(formula) |
| 문자 양식 | `이름`(title) · `문자 양식`(text) · `사용`(checkbox) · `학생`(relation→**학생 과목별 페이지**) |
| 과제 M | 빈 이름의 title · `과제`(relation→과제) — 마스터 테이블. 행 1건뿐이고 모든 과제 행이 이것을 가리킨다 |

### 이름이 오해를 부르는 relation

relation 속성의 **이름과 실제 대상 DB가 다릅니다.** 위 표에서 굵게 표시한 것들이 그렇습니다.

| 속성 | 있는 곳 | 실제 대상 |
|---|---|---|
| `학생` | 출석부 | `학생 과목별 페이지` (`학생` DB가 아닙니다) |
| `학생` | 문자 양식 | `학생 과목별 페이지` |
| `이름 붙여넣기` | 과제 · 시험 · 수강료 납부 · 재원생 상담 | 전부 `학생 과목별 페이지` |

출석부·과제·시험·수강료 납부·재원생 상담에서 사람 이름을 얻으려면 `학생 과목별 페이지`를 거쳐 `학생` DB까지 두 단계를 가야 합니다. 한 단계로 끝난다고 보고 짠 조회는 빈 결과를 냅니다.

지문이 맞지 않으면 조용히 넘어가지 않습니다. 어느 데이터베이스가 어떤 속성 때문에 어긋났는지 사용자에게 보고하고 멈춥니다. 이는 템플릿 버전이 다르거나 사용자가 속성 이름을 바꾼 경우입니다.

### 지문표에 넣지 않는 속성

**`학생 과목별 페이지` 의 `클로드 문자`(text) 는 지문이 아닙니다.** 최초 스캔 이후에 추가된 속성이라, 그 전에 템플릿을 복제한 사본에는 없을 수 있습니다. 지문에 넣으면 이 속성 하나 때문에 11개 스킬 전부가 연결 단계에서 멈춥니다. 이 속성이 실제로 필요한 것은 `academy-message` 하나뿐이므로, **그 스킬이 시작할 때 있는지 확인**하고 없으면 그 스킬만 안내하고 멈춥니다(`academy-message` 「시작 전에 읽는다」).

같은 기준을 앞으로 추가되는 속성에도 적용합니다 — **구매자 사본마다 있고 없고가 갈릴 수 있는 속성은 지문표가 아니라 그것을 쓰는 스킬의 시작 확인으로 옮깁니다.**

## DB별 쓰기 불가 속성

`domain-rules.md` 「쓰기 불가 속성」이 가리키는 권위 목록입니다. **formula·rollup·button 에는 값을 쓰지 않습니다** — 무시되거나 실패합니다. 각 쓰기 스킬의 「쓰지 않는 것」은 이 표를 가리키고 자기 DB 한 줄만 남깁니다. 출처는 `templates/2027-academy-operation-pro/schema-map.md` 의 실측 스캔입니다.

| 데이터베이스 | formula | rollup | button |
|---|---|---|---|
| 학생 | `학년` · `참여 요일 및 시간` | — | `국어` · `영어` · `수학` · `과학` · `퇴원` |
| 학생 과목별 페이지 | 수식 40개 — `KPI 점수` · `KPI 분석` · `가변 문자` · `비가변 문자` · `문자 필터` · `사용하는 양식` · `상담 관리` · `수강료미납현황` · `최근출결상태` · `최근시험명` · `최근성적` · `최근평균` · `최근시험피드백` · `저번과제` · `저번과제평가` · `저번과제피드백` · `최근수업` · `최근과제안내` · `특이사항(수식)` · `특이사항 문자` · `개별 페이지 링크` · `클래스 공지 링크` · `위클리 출결/시험/과제` · `최근 상담 날짜/내용` · `퇴원생` · 요일별 수식 · `참여 요일 및 시간` · `최근평가` | `시작 시간` · `참여 요일` | `출석` · `미출석` · `지각` · `문자 전송` |
| 클래스 | `오늘 출석 인원` | — | `공지사항 생성` |
| 출석부 | `보강 디데이` · `출석 문자` | `클래스` | — |
| 과제 | `DP` · `저번 과제` · `클래스(그룹)` · `평가 점수` · `과제 문자` · `필터` | `클래스` | — |
| 시험 | `DP` · `성적(%)` · `평균` · `시험 문자` · `시험 유형` · `클래스(그룹)` · `필터` | `클래스` · `시험 유형(그룹)` | — |
| 시험 카테고리 | `시험 날짜` · `평균` | — | — |
| 수강료 납부 | `납부 금액` · `납부 문자` · `세부 상태` · `미납 알림` · `클래스` | — | — |
| 납부 월 | 없음 | 없음 | 없음 |
| 재원생 상담 | `필터` | `클래스` | — |
| 신입생 | `학년` | — | `재원생 등록` |
| 학교 | — | `인원 수` | — |
| 클래스 공지사항 | `링크` · `공유 링크` | — | — |
| 문자 양식 | 없음 | 없음 | 없음 |
| 과제 M | 없음 | 없음 | 없음 |

`학년`(학생·신입생)만 쓰기 경로가 따로 있습니다 — 값을 넣을 곳은 `학년 수정`(number)이고, formula 인 `학년` 이 그 값을 읽습니다.

**버튼은 클로드가 누를 수 없습니다.** 값을 쓸 수 없는 것과 별개로 실행도 못 합니다 — 버튼이 하는 일이 필요하면 원장에게 눌러 달라고 안내합니다(`academy-enroll`).

## 제목 속성이 빈 데이터베이스

다음 데이터베이스들은 제목 속성의 **이름 자체가 빈 문자열**입니다:
- `출석부`
- `과제`
- `시험`
- `수강료 납부`
- `재원생 상담`
- `과제 M`

이는 설계된 것이므로 채우려 하지 않습니다. SQL 조회에서 `SELECT *`를 쓰고 빈 이름 컬럼을 직접 지정하지 않습니다. 지정하면 파싱 오류가 납니다.
