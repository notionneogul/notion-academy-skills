# 학원 관리 PRO 클로드 스킬 세트

「학원 관리 PRO」 노션 템플릿을 클로드와 함께 쓰기 위한 스킬 세트다.

## 설치

저장소를 클론한 뒤 `notion-academy-skills` 폴더 안에서 실행한다.

```bash
git clone https://github.com/notionneogul/notion-academy-skills.git
cd notion-academy-skills
mkdir -p ~/.claude/skills
cp -r skills/* ~/.claude/skills/
```

클로드에서 다음처럼 말한다.

```
학원 템플릿 연결해줘
```

## 스킬

원장이 위험도를 한눈에 보도록 읽기 전용과 쓰기로 나눈다.

### 읽기 전용

노션에 값을 쓰지 않는다. `academy-doctor` 만 예외로, 건별 승인을 받은 값 수정을 한다.

| 스킬 | 설명 |
|---|---|
| `academy-setup` | 복제한 템플릿 페이지를 연결하고 데이터베이스 15개의 스키마를 검증한다 |
| `academy-insight` | 오늘 할 일·이탈 위험 학생·상담 준비 자료를 브리핑한다 |
| `academy-doctor` | 빈 행·정합성 위반·중복 입력 등 데이터 오류를 점검한다. 기본은 읽기 전용이며, 고칠 수 있는 항목은 건별 승인을 받은 뒤에만 값을 수정한다. 행을 옮기거나 지우지는 않는다 |

### 쓰기

전부 미리보기 표를 보여주고 **명시적 승인**을 받은 뒤에만 노션에 쓴다.

| 스킬 | 쓰는 DB | 설명 |
|---|---|---|
| `academy-attendance` | 출석부 | 출결을 입력·수정한다. 반 전체 출석, 개인 지각·결석, 보강 예약·완료 처리를 다룬다 |
| `academy-homework` | 과제 · 과제 M | 과제를 입력하고 직전 과제의 평가·피드백을 채운다. 반 전체 과제는 `과제 M` 으로 묶는다 |
| `academy-exam` | 시험 카테고리 · 시험 | 시험 점수를 입력한다. 카테고리를 먼저 만들어 총점을 기록한 뒤 학생별 점수와 재시험 점수를 붙인다 |
| `academy-counsel` | 재원생 상담 | 재원생 상담 기록을 입력한다. 원장이 말한 내용만 문장으로 다듬어 넣는다 |
| `academy-enroll` | 신입생 · 학교 · 학생 과목별 페이지(클래스 배정, 버튼 없는 과목은 행 생성) · 수강료 납부 | 신입생을 재원생으로 등록한다. 신입생 행을 채운 뒤 `재원생 등록` 버튼을 원장이 누르도록 안내하고, 버튼이 만들지 않는 학교·클래스 배정·수강료 행은 직접 쓴다. 과목 페이지는 버튼이 있는 과목(국어·영어·수학·과학)이면 버튼에 맡기고, 없는 과목(물리 등)이면 직접 만든다 |
| `academy-tuition` | 수강료 납부 · 납부 월(없는 연월이면 생성) | 수강료 납부 상태를 입력한다. 개별 완료 처리와 월 단위 청구 행 일괄 생성을 하며, 퇴원생과 이미 청구된 학생은 자동으로 제외한다 |
| `academy-message` | 학생 과목별 페이지 (속성만) | 학부모에게 보낼 문자 초안을 학생별로 만든다. 새 행은 만들지 않고 `클로드 문자` 속성만 채우며, 발송은 원장이 노션 버튼을 눌러 한다 |

`academy-core` 는 위 스킬들이 공유하는 규칙 문서 보관소다. 직접 호출하지 않는다.

## 하지 않는 것

쓰기 스킬 7개에 공통으로 적용되는 핵심은 넷이다.

- **승인 없이 쓰지 않는다.** 만들거나 고칠 값을 미리보기 표로 전부 보여주고 명시적 승인을 받은 뒤에만 노션에 쓴다
- **자동으로 발송하지 않는다.** `academy-message` 는 문자 초안을 `클로드 문자` 속성에 채우기만 하고, 발송 버튼은 원장이 직접 누른다
- **행을 삭제하지 않는다.** 되돌리기는 이번 실행에서 자기가 쓴 것에 한하고 두 갈래다 — **새로 만든 행**은 `🗃️ 샘플 보관` 페이지로 옮기고, **고친 값**은 고치기 전 값으로 되돌린다(건별 승인). 규칙은 `academy-core/references/write-gate.md` 6단계 한 곳에만 있고 일곱 쓰기 스킬이 그것을 따른다
- **데이터베이스 스키마(속성 추가·옵션 변경)를 바꾸지 않는다.**

그 외:

- `academy-setup`, `academy-insight` 는 노션에 아무것도 쓰지 않는다
- `academy-doctor` 는 기본이 읽기 전용이다. 고칠 수 있는 항목도 제안만 하고, 건별 승인을 받아야 값을 수정한다. 행을 옮기거나 지우는 것은 이 스킬의 몫이 아니다
- `academy-enroll` 은 `학생` DB 에 행을 직접 만들지 않는다. `신입생` 행을 채운 뒤 원장이 `재원생 등록` 버튼을 누르도록 안내하고, 버튼이 만든 결과를 조회해 확인한다
- `academy-message` 는 새 행을 만들지 않는다. 이미 있는 `학생 과목별 페이지` 행의 `클로드 문자` 속성만 채운다

시트·CSV 임포트(`academy-import`)와 샘플 데이터 정리는 이후 별도 계획으로 추가될 예정이다.
