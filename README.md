# 학원 관리 PRO 클로드 스킬 세트

「학원 관리 PRO」 노션 템플릿을 클로드와 함께 쓰기 위한 스킬 세트입니다.

> **처음이신가요?** 터미널을 한 번도 열어 본 적 없어도 따라올 수 있게 쓴 **[설치 가이드(INSTALL.md)](INSTALL.md)** 부터 보십시오. Claude Code 설치부터 순서대로 안내합니다.

## 설치

이 스킬 세트는 **Claude Code 에서만** 동작합니다. claude.ai 웹사이트나 휴대폰 앱에서는 쓸 수 없습니다.

### 1. 스킬 폴더 12개를 내 컴퓨터에 넣습니다

터미널 없이 하는 방법입니다.

1. 다음 주소를 브라우저에서 엽니다: <https://github.com/notionneogul/notion-academy-skills>. 초록색 `Code` 버튼을 누르고 `Download ZIP` 을 선택합니다.
2. 내려받은 ZIP 의 압축을 풉니다.
3. 압축 푼 폴더 안의 **`skills` 폴더에 들어 있는 12개 폴더**를 스킬 위치로 끌어넣습니다.
   - 맥: `~/.claude/skills`
   - 윈도우: `C:\Users\<사용자이름>\.claude\skills`

**`skills` 폴더를 통째로 넣으면 안 됩니다. 그 안의 12개를 넣어야 합니다.** 폴더 여는 법, 숨김 폴더 보는 법, 잘못 넣었을 때의 모습은 [INSTALL.md 3단계](INSTALL.md)에 그림과 함께 있습니다.

<details>
<summary>터미널을 써 본 적 있다면 이 방법이 더 빠릅니다</summary>

아래 명령을 위에서부터 차례로 실행합니다. `git` 이 설치되어 있어야 합니다.

```bash
git clone https://github.com/notionneogul/notion-academy-skills.git
cd notion-academy-skills
mkdir -p ~/.claude/skills
cp -r skills/* ~/.claude/skills/
```

</details>

### 2. 노션 커넥터를 연결합니다

Claude Code 채팅창 왼쪽 아래 `+` → `커넥터` → **Notion** 을 고르고, 브라우저가 열리면 노션에 로그인해 **허용**을 누릅니다. 터미널이 편하시면 `claude mcp add --transport http --scope user notion https://mcp.notion.com/mcp` 한 줄이면 됩니다.

**노션 API 키는 만들지 않으셔도 됩니다.** `my-integrations` 에서 키를 발급받는 방식은 개발자용이고, 여기서 쓰는 커넥터는 로그인해서 허용만 누르면 끝입니다.

연결 뒤 "노션에서 학원 관리 PRO 페이지 찾아줘" 라고 해서 못 찾으면, 그 페이지가 허용 범위 밖인 것입니다 — 노션에서 템플릿 페이지 → `···` → `연결 항목` → Claude 를 추가합니다. 화면별 안내는 [INSTALL.md 2단계](INSTALL.md)에 있습니다.

### 3. 연결합니다

Claude Code 에서 다음처럼 말합니다.

```
학원 템플릿 연결해줘
```

## 스킬

원장이 위험도를 한눈에 보도록 읽기 전용, 연결·정리, 쓰기, 발송 넷으로 나눕니다. 뒤로 갈수록 되돌리기가 어렵고, 맨 뒤의 발송은 아예 되돌릴 수 없습니다.

### 읽기 전용

노션에 행을 만들지도, 옮기지도 않습니다. `academy-doctor` 만 예외로, 건별 승인을 받은 값 수정을 합니다.

| 스킬 | 설명 |
|---|---|
| `academy-insight` | 오늘 할 일·이탈 위험 학생·상담 준비 자료를 브리핑합니다 |
| `academy-doctor` | 빈 행, 서로 맞지 않는 값, 중복 입력 같은 데이터 오류를 점검합니다. 기본은 읽기 전용이며, 고칠 수 있는 항목은 건별 승인을 받은 뒤에만 값을 수정합니다. 행을 옮기거나 지우지는 않습니다 |

### 연결·정리

첫날 한 번 쓰는 스킬입니다. 행을 만들지도 지우지도 않지만, **행을 옮깁니다** — 그래서 읽기 전용도 쓰기도 아닙니다.

| 스킬 | 설명 |
|---|---|
| `academy-setup` | 복제한 템플릿 페이지를 클로드에 연결하고, 데이터베이스 15개가 제자리에 있는지 확인합니다. 이어서 제작자 샘플 데이터를 `🗃️ 샘플 보관` 페이지로 치웁니다 — 무엇을 몇 행 옮기는지 표로 보여주고 승인을 받은 뒤에만 하며, 보관 페이지에 남긴 「되돌리기 목록」으로 「샘플 되돌려줘」 하면 되돌아옵니다 |

### 쓰기

전부 미리보기 표를 보여주고 **명시적 승인**을 받은 뒤에만 노션에 씁니다.

| 스킬 | 쓰는 DB | 설명 |
|---|---|---|
| `academy-attendance` | 출석부 | 출결을 입력·수정합니다. 반 전체 출석, 개인 지각·결석, 보강 예약·완료 처리를 다룹니다 |
| `academy-homework` | 과제 · 과제 M | 과제를 입력하고 직전 과제의 평가·피드백을 채웁니다. 반 전체 과제는 `과제 M` 으로 묶습니다 |
| `academy-exam` | 시험 카테고리 · 시험 | 시험 점수를 입력합니다. 카테고리를 먼저 만들어 총점을 기록한 뒤 학생별 점수와 재시험 점수를 붙입니다 |
| `academy-counsel` | 재원생 상담 | 재원생 상담 기록을 입력합니다. 원장이 말한 내용만 문장으로 다듬어 넣습니다 |
| `academy-enroll` | 신입생 · 학교 · 학생 과목별 페이지(클래스 배정, 버튼 없는 과목은 행 생성) · 수강료 납부 | 신입생을 재원생으로 등록합니다. 신입생 행을 채운 뒤 `재원생 등록` 버튼을 원장이 누르도록 안내하고, 버튼이 만들지 않는 학교·클래스 배정·수강료 행은 직접 씁니다. 과목 페이지는 버튼이 있는 과목(국어·영어·수학·과학)이면 버튼에 맡기고, 없는 과목(물리 등)이면 직접 만듭니다 |
| `academy-tuition` | 수강료 납부 · 납부 월(없는 연월이면 생성) | 수강료 납부 상태를 입력합니다. 개별 완료 처리와 월 단위 청구 행 일괄 생성을 하며, 퇴원생과 이미 청구된 학생은 자동으로 제외합니다 |
| `academy-message` | 학생 과목별 페이지 (속성만) | 학부모에게 보낼 문자 초안을 학생별로 만듭니다. 새 행은 만들지 않고 `클로드 문자` 속성만 채우며, 이 스킬이 보내지는 않습니다 — 원장이 노션 버튼을 누르시거나 `academy-send` 로 승인을 거쳐 보내십니다 |

### 발송

학부모 휴대폰으로 **실제 문자가 나갑니다.** 앞의 셋과 성격이 다릅니다 — 노션에 쓴 것은 되돌릴 수 있지만, 보낸 문자는 회수할 수 없습니다. 몇 건이 어느 채널로 어느 번호에서 나가는지, 잔액이 얼마이고 예상 요금이 얼마인지를 미리보기로 보여드리고 **명시적 승인**을 받은 뒤에만 보냅니다. 노션에는 아무것도 쓰지 않습니다.

| 스킬 | 보내는 곳 | 설명 |
|---|---|---|
| `academy-send` | 카카오 알림톡 · 문자 | 학부모에게 알림톡 또는 문자를 보냅니다. 예약 발송과 예약 취소, 발송 결과 확인과 실패한 건만 골라 다시 보내기를 함께 다룹니다. 쓰시기 전에 「문자 발송 세팅해줘」로 발송 계정을 한 번 연결해야 하고, 문자를 보내지 않으실 거면 이 스킬은 쓰지 않으셔도 됩니다 |

`academy-core` 는 위 스킬들이 공유하는 규칙 문서 보관소입니다. 직접 호출하지 않습니다.

## 하지 않는 것

쓰기 스킬 7개에 공통으로 적용되는 핵심은 셋입니다.

- **승인 없이 쓰지 않습니다.** 만들거나 고칠 값을 미리보기 표로 전부 보여주고 명시적 승인을 받은 뒤에만 노션에 씁니다
- **행을 삭제하지 않습니다.** 되돌리기는 이번 실행에서 자기가 쓴 것에 한하고 두 갈래입니다 — **새로 만든 행**은 `🗃️ 샘플 보관` 페이지로 옮기고, **고친 값**은 고치기 전 값으로 되돌립니다(건별 승인). 규칙은 `academy-core/references/write-gate.md` 6단계 한 곳에만 있고 일곱 쓰기 스킬이 그것을 따릅니다
- **데이터베이스의 구조를 바꾸지 않습니다.** 속성을 새로 만들거나 선택지를 고치지 않습니다. 값을 채울 뿐입니다.

이 셋은 스킬 문서에 「승인 없이 쓰지 않는다」 로 못 박혀 있는 규칙이고, 원장이 승인하지 않으면 어떤 스킬도 이 선을 넘지 않습니다.

발송 스킬 `academy-send` 에는 셋이 더 붙습니다. 되돌릴 수 없기 때문입니다.

- **승인 없이는 한 통도 보내지 않습니다.** 대상과 내용, 건수, 잔액을 미리보기로 보여드리고 명시적으로 승인하신 뒤에만 보냅니다
- **보낸 문자는 되돌릴 수 없습니다.** 노션에 쓴 것은 되돌릴 수 있지만 발송은 다릅니다. 예약해 두시면 그 시각 전까지는 취소하실 수 있습니다
- **API 키를 클로드가 입력하거나 화면에 보여주지 않습니다.** 설정 파일에 직접 넣으시면 있는지만 확인하고 읽어서 쓸 뿐, 값을 화면에 옮기지 않습니다

그 외:

- `academy-insight` 는 노션에 아무것도 쓰지 않습니다. `academy-setup` 은 연결 단계에서는 아무것도 쓰지 않고, 샘플 데이터 정리에서만 승인을 받아 행을 보관 페이지로 옮깁니다. 옮긴 행의 목록을 보관 페이지에 적어 두므로 되돌릴 수 있고, **그 페이지를 지우면 되돌릴 수 없습니다**
- `academy-doctor` 는 기본이 읽기 전용입니다. 고칠 수 있는 항목도 제안만 하고, 건별 승인을 받아야 값을 수정합니다. 행을 옮기거나 지우는 것은 이 스킬의 몫이 아닙니다
- `academy-enroll` 은 `학생` DB 에 행을 직접 만들지 않습니다. `신입생` 행을 채운 뒤 원장이 `재원생 등록` 버튼을 누르도록 안내하고, 버튼이 만든 결과를 조회해 확인합니다
- `academy-message` 는 새 행을 만들지 않습니다. 이미 있는 `학생 과목별 페이지` 행의 `클로드 문자` 속성만 채웁니다. 그리고 **이 스킬 자체는 문자를 보내지 않습니다** — 스킬 문서에 「발송하지 않는다」 로 못 박혀 있습니다. 초안을 채워 둘 뿐이고, 그 초안이 학부모에게 나가는 것은 원장이 노션에서 발송 버튼을 누르실 때이거나 `academy-send` 로 승인을 거쳐 보내실 때뿐입니다. 문자 초안을 채웠다는 것만으로는 한 통도 나가지 않습니다
- `academy-send` 는 노션에 아무것도 쓰지 않습니다. 대상과 번호, 문자 내용을 읽기만 하고 밖으로 보냅니다 — 발송한 뒤에도 `전송완료` 체크박스를 켜지 않습니다
