# 학원 관리 PRO 클로드 스킬 세트

「학원 관리 PRO」 노션 템플릿을 클로드와 함께 쓰기 위한 스킬 세트다.

## 설치

저장소를 클론한 뒤 `notion-academy-skills` 폴더 안에서 실행한다.

```bash
git clone https://github.com/notionneogul/notion-academy-skills.git
cd notion-academy-skills
mkdir -p ~/.claude/skills
cp -r skills/* ~/.claude/skills/
```

클로드에서 다음처럼 말한다.

```
학원 템플릿 연결해줘
```

## 스킬

| 스킬 | 설명 |
|---|---|
| `academy-setup` | 복제한 템플릿 페이지를 연결하고 데이터베이스 15개의 스키마를 검증한다 |
| `academy-insight` | 오늘 할 일·이탈 위험 학생·상담 준비 자료를 브리핑한다 (읽기 전용) |
| `academy-doctor` | 빈 행, 정합성 위반, 중복 입력 등 데이터 오류를 점검한다. 기본은 읽기 전용. 고칠 항목은 제안만 하고, 건별 승인을 받아야 **값을** 수정한다. 행을 옮기거나 지우지는 않는다 |
| `academy-core` | 위 스킬들이 공유하는 규칙 문서 보관소. 직접 호출하지 않는다 |

## 대표 발화

- "학원 템플릿 연결해줘"
- "오늘 뭐 해야 해?"
- "위험한 학생 있어?"
- "OO 학생 상담 준비해줘"
- "데이터 점검해줘"

## 요구 사항

- Claude Code
- Notion 커넥터 (템플릿 페이지가 커넥션에 추가되어 있어야 한다)
- 「학원 관리 PRO」 템플릿 v2 이상

## 하지 않는 것

- 알림톡·문자를 자동으로 발송하지 않는다
- 데이터베이스 스키마(속성 추가·옵션 변경)를 바꾸지 않는다
- `academy-setup`, `academy-insight` 는 노션에 아무것도 쓰지 않는다
- `academy-doctor` 는 기본이 읽기 전용이지만, 오류를 고칠 수 있을 때는 제안 후 **사용자의 건별 승인을 받아야만** 수정한다. 승인 없이 스스로 값을 바꾸지 않는다
- `academy-doctor` 가 하는 쓰기는 **값 수정뿐이다.** 행을 보관 페이지로 옮기거나 휴지통으로 보내거나 삭제하지 않는다. 행을 치워야 하는 문제는 목록으로 보고만 하고, 노션에서 직접 처리하도록 안내한다

출결 입력, 문자 발송, 행 정리(보관 페이지로 이동 등) 같은 쓰기 기능은 이후 단계에서 별도 계획으로 추가될 예정이다.
